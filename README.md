# new-projects

Sofia's standing briefs (Claude skills) for projects that live in their own Claude Projects.
Each folder under `skills/` is one brief: a `SKILL.md` plus any reference files.
Upload the packaged `.skill` file (or the folder) in claude.ai → Settings → Capabilities → Skills so every chat can load it.

| Skill | What it carries |
|---|---|
| `skills/korean-project` | Korean (Hangul → B1): operating brief + `references/korean-ladder.md` |
| `skills/iraqi-arabic-project` | Iraqi Arabic (script → A2): operating brief + `references/iraqi-ladder.md` |
| `skills/mika-land-tv` | Mika Land TV animated series: rules, cast, roadmap snapshot, tried-and-rejected list |

Snapshots inside the briefs go stale; the live artifacts (roadmap pages, the Series Bible) win when they disagree.
